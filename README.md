# kassawmar

אפליקציית שיחות קוליות בדפדפן, עם הצפנה מקצה לקצה (WebRTC / DTLS-SRTP).

- כל משתמש מקבל קוד של 6 ספרות.
- מקלידים את הקוד של הצד השני ולוחצים "התקשר", או שולחים קישור הזמנה.
- הקול עובר ישירות בין המכשירים. השרת רק מחבר בין הצדדים ולא שומע את השיחה.
- בזמן שיחה מוצג קוד אבטחה. אם הוא זהה אצל שני הצדדים, אף אחד לא מאזין באמצע.
